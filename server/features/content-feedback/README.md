# content-feedback

## 职责

承载公众号导入、文章与图文匹配、内容表现反馈、项目发现反馈，以及基于反馈生成的技能调整提案。确定性的文章洞察、项目发现反馈、账号策略建议、导入字节流解析和匹配规则位于 `domain/`。

## 依赖边界

反馈规则和反馈快照组装应保持可测试；数据库、文件和模型调用由 application 或 platform 适配层注入。确定性规则已下沉到 `domain/`，文章正文关联、公众号复盘读模型装配、图文反馈 I/O、反馈调整和图文技能反哺均位于 `application/`。根目录 `index.mjs` 是稳定业务入口，不保留兼容 facade。
