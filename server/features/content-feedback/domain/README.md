# content-feedback/domain

## 职责

承载不依赖 Store、文件系统或模型编排的内容反馈规则：公众号历史文章洞察、项目发现反馈调整、账号策略建议、文章反馈快照和图文反馈特征计算。

## 依赖边界

这里只接收输入并返回确定性结果，可依赖共享领域规则，但不访问数据库、文件、网络或平台适配器。需要持久化、文件读取或模型生成的流程由上层 application 组合；公众号反馈 Prompt 的不可信上下文封装仍保留在根 facade，以隔离平台 LLM 基础设施。

当前领域模块包括公众号文章/图文反馈快照、导入解析、文章匹配、内容洞察、项目反馈、策略建议、图文技能目标选择和技能文本精确替换。
