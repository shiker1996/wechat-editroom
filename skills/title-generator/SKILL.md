# 标题生成

根据锁定简报、事实基座和文章生成 5 个有差异的标题，并推荐一个。标题以真实的点击理由为目标，准确表达正文的核心事实、冲突或判断。

优先保留读者能识别的事件、主体或具体话题，并说明它与目标读者的关系。不同候选可从事件影响、读者问题、事实反差或核心判断切入；语言清楚、具体，兼顾自然搜索词。

标题承诺必须由正文和证据兑现。涉及法律后果、劳动权益或福利资格时，按适用辖区核对法律或官方原始材料；美国失业保险核对具体州。材料只支持某来源的说法时，标题应明确归因。

编排模式按调用提供的 `decision.title_plan` 工具和结构返回结果；独立使用时返回：

```json
{"titleCandidates":[{"title":"标题","reason":"理由"}],"selectedTitle":"唯一推荐标题","hotspotAnchor":"必要事件或主体名","coreKeywords":["自然使用的关键词"]}
```
