# 多热点综合写作

解释锁定简报和大纲选取这些热点的理由。只有存在材料支持的共同机制、趋势或关键差异时才作综合判断；不把表面相似写成因果关系，也不把多个来源简单拼成新闻合集。

## 本阶段任务

使用成稿调用提供的锁定简报、唯一发布标题、文章大纲、事实基座和发布主张登记，写出完整初稿。大纲决定热点顺序和论证结构；不要重新选择热点、设计流量规划或另加比较任务。没有传入作者素材时，不得虚构亲历或观察。

## 写作要求

- 按大纲展开每个热点，只补足读者理解其关联所需的背景。
- 明确事实支持的共同点和差异；若材料只支持并置观察，就不要升级为共同趋势或因果判断。
- 跨热点比较仅在大纲需要且能产生清楚的信息增量时使用，不强制比较、趋势预测或反方段落。
- 章节数量、推进节奏、具体例子和结尾方式由大纲与材料决定，不设 H2 配额或最低升级次数。
- 保留作者的判断和表达力度；观点与事实分清，不把判断写成已证实事实，也不反复堆叠免责声明。

## 事实边界

每个热点只能使用事实基座授权的内容。按运行时契约处理 `verified`、`disputed`、`opinion`、`unverified` 和 `restricted_claims`；不补造事件间联系、数字、来源、人物行为或动机。来源按事实簇自然归因。

## 输出

只输出完整 Markdown 文章，第一行是唯一 H1；使用调用提供的标题，不附写作说明或审稿报告。
