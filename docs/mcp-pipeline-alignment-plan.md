# MCP 与内部业务流程对齐

目标：外部 Agent 在不配置工作台模型的情况下执行各业务流程；工作台负责共用提示词、阶段顺序、校验、状态和产物归档。内部模型路径继续可用。

## 实施顺序与验收

1. **批次研判**：打标和事件卡的输入、结果校验与内部规则对齐；外部逐阶段执行读者初筛、事件研判、选题和评分，验证文章与图文候选都能入池。当前已有研判桥接，需真实候选和大批次回归。
2. **文章与审稿**：复用事实基座、简报、规划、写作、审稿和发布门禁；外部 Agent 接收各阶段原始输入并提交输出，验证终稿和失败恢复。
3. **排版与封面**：共享设计方案校验、正文保真、HTML 检查、截图及归档；分别验证外部与内部入口生成的产物和失败处理。
4. **图文**：对齐故事板、设计方案、生成中浏览器审计、截图和交付门禁；覆盖事件、工具和自定义图文。
5. **其他流程**：覆盖每日早报、教程、突发分析、独立审稿以及重试恢复，分别验证输入和交付契约。
6. **对话 Agent**：核对画像、编辑室、独立写作和自定义图文的上下文、工具权限及保存行为，提供外部 Agent 所需的受控能力。
7. **端到端**：在独立测试副本通过 MCP、Skill 和 CLI，从初始化、采集、研判到文章、排版、封面和图文完成真实回归；检查断点恢复、重复提交、大批次与产物链接。

每项先核对现有实现和 MCP 入口，抽出或复用业务阶段，再增加外部模型执行的接入；用同一组输入比较内部与外部的校验、状态与产物。暂停恢复时避免重复执行不可幂等操作。
