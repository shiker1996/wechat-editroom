# 见字首轮公开展示素材

这份素材用于项目首次公开展示，目标是让读者先看懂工作流，再决定是否安装和 Star。

## GitHub 发布说明

### 标题

见字：从热点开始写一篇文章的本地 AI 公众号工作台

### 正文

见字不是“输入一个主题、生成一篇文章”的聊天框，而是一条从信息源开始、可追溯到交付物的本地内容生产流水线：

```text
热点 → 事件与事实 → 候选选题 → 编辑决策 → 文章 / 图文 → 排版与产物
```

这次公开展示包含：

- 真实工作台界面与热点全景截图
- 选题池、AI 编辑会和文章编辑器
- 微信排版预览、封面和社交图文入口
- 一段从总览到交付的真实工作流教程视频
- 无需配置模型即可查看的 [在线真实界面展示](https://wechat-newsroom-guide.vercel.app/)

完整工作台仍然在本地运行，数据默认保存在本机。

项目地址：https://github.com/shiker1996/wechat-editroom

如果你也在做公众号、技术内容或 AI 内容生产，欢迎 Star，并告诉我你最想接入的内容来源。

## 首轮传播计划

1. 第一天：发布 GitHub Release，更新 README 首屏，并在项目介绍中放在线教程链接。
2. 第二天：发布教程视频 + 热点全景截图，重点解释“从选题开始”的差异。
3. 第三天：发布一篇真实使用记录，说明从热点到成稿的具体步骤和耗时。
4. 第四至七天：根据 Issue 和评论补充安装问题、来源接入和截图说明；只推广真实存在的能力。
