04 / QUICK START

五分钟，走完第一条
从热点到文章的路径。

桌面版要求Windows 10/11 · x64推荐直接下载安装包；源码开发才需要 Node.js 24+
01

下载并安装桌面版

Windows 用户推荐从 GitHub Releases 下载最新安装包。安装时可以选择应用安装目录和运行数据目录；文章、图片、日志与 RSSHub 依赖会写入运行数据目录。

打开最新 Release ↗安装后首次启动会打开配置向导
02

接入一个模型服务

首次启动会打开应用内引导。在“运行与配置 → 模型接入”添加 OpenAI 兼容服务，填写 Base URL、模型名和 API Key，先完成连接测试。

配置路径运行与配置 → 模型接入 → 添加模型
03

从一个批次跑到交付

依次完成采集 → 研判 → 编辑决策 → 成稿 → 审稿 → 排版，再从产物柜查看公众号 HTML、封面和社交图文。
