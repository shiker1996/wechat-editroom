03 / EXTERNAL AGENTS

把见字工作流，
带进你的 Agent。

外部 Agent 使用自己的会话模型，通过本机 MCP 调用见字的采集、研判和产物能力。见字负责保存文章与视觉产物，并执行相应校验和归档。

01

安装并启动见字

独立使用可安装 Windows 10/11 x64 桌面版。接入外部 Agent 时，按项目指南克隆源码并运行初始化向导；见字工作台与 Agent 在同一台电脑访问本机项目。

下载 Windows 桌面版 ↗外部 Agent 安装说明 →
02

准备 AI 执行环境

选择见字本地 Runtime 时，配置供应商、模型与阶段路由；选择 Codex Runtime 时，连接 Codex 账号。使用外部 Agent 时，按客户端指南连接本机 MCP 与 Skills，沿用当前会话模型。

查看外部 Agent 接入说明 →
03

从批次走到内容交付

配置采集源并测试，然后完成采集、研判和编辑决策。文章由 Agent 写作并审稿；排版、封面和图文产物可提交工作台校验、渲染并归档，完成后从产物入口查看。

WHAT YOU CAN DELIVER

从一个候选，走到一组可继续编辑和发布的内容。

  • 公众号文章与排版 HTML
  • AI 视觉封面
  • 事件、工具或自定义图文
产物保存在见字工作台，可从对应入口预览、检查与下载。
